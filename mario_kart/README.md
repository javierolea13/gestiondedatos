# Mario Kart - Registro de Carreras

Aplicación para llevar el registro de victorias y estadísticas con tus amigos en Mario Kart.

## Uso

```bash
cd mario_kart
python main.py
```

## Funcionalidades

### Gestión de Jugadores
- Agregar jugadores (2-4 por torneo)

### Torneos (Grand Prix)
- Crear torneos con copas oficiales de Mario Kart 8 Deluxe (8 copas disponibles)
- Crear torneos con pistas personalizadas
- Cada torneo tiene 4 carreras
- Registrar posiciones de cada carrera

### Rankings y Estadísticas
- **Ranking global**: puntos totales, torneos ganados, podios, posición promedio
- **Ranking por pista**: quién es el mejor en cada pista
- **Mejor/peor pista**: descubre en qué pistas destacas y en cuáles no
- **Enfrentamiento directo**: compara el historial entre dos jugadores

## Sistema de Puntos

Se usa el sistema de puntos de Mario Kart:

| Posición | Puntos |
|----------|--------|
| 1°       | 15     |
| 2°       | 12     |
| 3°       | 10     |
| 4°       | 8      |
