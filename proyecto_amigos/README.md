# Proyecto de Amigos

Sistema para gestionar información de tu grupo de amigos: contactos, cumpleaños, eventos y más.

## Estructura

- `amigos.py` - Clase principal para gestionar amigos
- `datos/amigos.json` - Base de datos de amigos en formato JSON
- `main.py` - Programa principal con menú interactivo

## Uso

```bash
cd proyecto_amigos
python main.py
```

## Funcionalidades

- Agregar nuevos amigos con sus datos de contacto
- Listar todos los amigos
- Buscar amigos por nombre
- Ver cumpleaños próximos
- Registrar eventos y salidas
- Editar y eliminar amigos
- Exportar datos a CSV
